# Norths-Funky-Forms
I am of the opinion that good paperwork = good roleplay. 
Paperwork should look aesthetically pleasing as well as official looking. Some paperwork takes time to complete, and some are short. 
It all depends on the intended use of the document - an NTRs/IAAs "command compliance review" will take more time to fill out than a witness deposition from security. I've tried to keep paperwork that's intended to be filled out by a standar crewmember as short as possible.
