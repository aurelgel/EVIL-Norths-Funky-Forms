[head=3][bold]STRUCTURAL CHECKS[/bold][/head]
( ) Walls properly aligned and reinforced.
( ) Floors plated, sealed, and pressure‑safe.
( ) No exposed girders or unsecured plating.
( ) Firelocks present and functional.

[head=3][bold]POWER & ELECTRICAL CHECKS[/bold][/head]
( ) APC installed and charging.
( ) Wiring intact, insulated, and color‑correct.
( ) No power loops or shorts detected.
( ) SMES/engine load unaffected by changes.

( ) Pipes connected and pressure‑stable.
( ) No harmful gases routed to distro.
( ) Air alarms functional and default‑configured.
( ) Vent/scrubber network intact.

( ) Radiation levels within acceptable range.
( ) Emitters, shielding, and containment unaffected.
